Open source

Selected GitHub projects

More on GitHub ↗

Kolor ↗

Kolor is a Swift library for working with color spaces and converting between them. It also provides palette generation, color-distance calculations, quantization, histograms, and image-analysis helpers.

Arbit ↗

Arbit is a Swift arithmetic project that experiments with signed values and custom numeric representations. Its README marks addition and multiplication as implemented, while subtraction, division, hexadecimal conversion, and square-root functions are still listed as work to do.

DateX ↗

DateX is an integer-based date and time type for Swift, designed to avoid the precision limits of floating-point time values. It uses a two-part 32-bit integer representation for precise time measurement.
