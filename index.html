Selected GitHub projects

More on GitHub

Kolor ↗

Kolor is a Swift library for working with color spaces and converting them. It also provides palette generation, color-distance calculations, quantization, histograms, and image-analysis helpers.

Arbit ↗

Arbit is a Swift math project, it enables arbitrary-precision arithmetic calculations and also gives developers many useful utilities, such as hexadecimal conversion and square-root functions. It is particularly fast when working with medium-sized numbers and string processing.

DateX ↗

DateX is an integer-based date and time type for Swift, designed to avoid the precision limits of floating-point time values. It uses a two-part 32-bit integer representation for precise time measurement.
