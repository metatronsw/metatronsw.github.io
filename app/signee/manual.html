Signee user manual

Clock

Refresh rate: The smaller value does not only change the appearance of the digits, it also uses less CPU resources and therefore drains the battery less. However, the accuracy of the measured time is not affected, it always works at maximum resolution and the display of values can be freely changed at any time.

Display mode: Sec - Shows only the elapsed seconds. Static - Always shows the minute and, if on, the hours. Dynamic - If a whole minute or hour has not elapsed, only the value is shown.

Separator: Free to choose, regardless of the phone's local settings.

Display fixed hour-minute: As long as the number is not more than 10, it takes up only one space and does not show the prefix 0. In static mode the number of empty hours is also displayed.

Display auxiliary timer: Shows the idle time or the time of a lap started. If the timestamp function is activated, the current time is also displayed.

Display actual time: In order to use it you must also authorise the auxiliary clock.

Display of precise time: If enabled, it will display times to 3 decimal places, but only if the clock is stopped, otherwise the update and display will depend on the refresh rate setting.

Sign Interval

Loop timer: At the specified intervals the period time meter is restarted, if the signal function is activated, it will be activated at the end. At the end of the period the counter will increment by one. 24 hours is the maximum period, with a setting of 0 seconds the function will be automatically inactive. The period time is always counted from the start of the stopwatch, regardless whether the function is activated or not.

Signals

Sound: Currently only the factory sounds of the phone are available, this will change in the future. There are 3 distinctions in the list: The signal is inaudible in silent mode. The signal can be heard in silent mode. In addition to the beep sound, there is also a vibration.

Screen flash: The phone screen will flash in the selected colour when the repeat period has ended. A choice of five colours.

Vibration: The phone will start to vibrate at the selected intensity when the repeat period has ended.

Speech

Say it: When the repetition period comes to an end, it will say the number of laps elapsed or the elapsed time, depending on the mode set. A minimum of 10 seconds is required between repeats. In the additional settings it is possible to set the words that the program will say next to the numbers.

SkipZeroValues: If the option is activated, it will not say zero seconds for whole minutes.

Prefix and Postfix words only work in the Count mode.

Counter

Shows the elapsed and remaining time set for the repeat and the laps completed. Touching the display brings up an adjustment panel where you can conveniently change the values on the fly. If the Counter Display is off, this is not possible, but the counter still works in the background. You can toggle the displayed items on and off individually.

Reset counter on new lap: If the switch is active, tapping the counter on the main screen will start a new round, but the repeat counter will also restart.

Counter mode: If activated, the central big time display will show only the number of laps elapsed instead of the time. You can manually increase each one by touching it, regardless of the timer or whether the stopwatch has been started.

Behaviour

Theme: Appearance, automatic or fixed day - night mode.

Copying time result to clipboard. Only the elapsed seconds, or in Automatic mode according to the currently set format.

Sending to clipboard: Automatically copies the current time to the clipboard when you exit. The format can be seconds or the commonly used setting.

Restoringl last session: Saves the current time after exit and reloads it when the program is restarted. If Continue last session is also enabled, it behaves as if the program was not closed ( like the factory apple stopwatch ). In the case of active Auto stop on exit, it will stop the counter when moving from one program to another or when closing.

Swap mark-lap button: It replaces / changes???/ the touch function of the auxiliary clock and the big main time counter on the main screen.

Hiding status bar: It hides the factory clock and the mobile phone's signal for signal strength and battery charge.

History

Use history: If it is not turned on, the program will still log the activity, it just does not display it and does not save it. So if you remember to turn it on later, you haven't lost anything.

You can display the separator lines and adjust the scrolling behaviour.

Auto mark interval: If enabled, a record is automatically made at the end of each repetition, with the time elapsed and the number of laps.
