Site map

Our website is built entirely without JavaScript! All animations use SVG and CSS to deliver the best possible speed and compatibility with the smallest possible footprint. We believe the future of the web lies in dynamically generated static pages and a minimalist approach. These pages are easy to move between hosting providers and can be conveniently updated and maintained through custom administration tools and AI assistance.

In our projects, we also enjoy using the Vapor server framework for dynamic websites and microservices, combined with HTML templates. With WebAssembly and Embedded Swift, we can address a wide range of requirements securely and in line with modern technical standards.
